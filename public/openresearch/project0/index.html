D: ActionPlan + VGGT on TRUMANS

Goal

ActionPlan (condmdi_smpl) already denoises sequence CLIP text plus a dense per-frame action-plan on empty-floor HML3D-272. It does not see geometry. The bet is a receding-horizon loop: persistent goal text c (“walk to the table”), frozen VGGT-Ω tokens sk from a short ego window, and a motion chunk xk from the ActionPlan prior — not a god’s-eye BEV, not a painted sphere, not a full-clip action-plan y.

Placement smoke (Track B) asked whether we can plant an HML3D walk in a TRUMANS room. That test is done. It is not the train set: planted captions are not about that room, and rejection sampling is not how CLOPS avoids furniture. Train data for D is native TRUMANS (text + ego + motion converted to 272).

SceMoS vs CLOPS vs us

SceMoS is text-to-scene interaction from an omniscient bird’s-eye RGB (DINOv2) plus a local heightmap. The couch is always in the image; the avatar never has to look for it. CLOPS is ego depth + GT segmentation, but the goal is a red sphere with an explicit mask — positioning, not language.

GoalScene sensorMotionNon-penetration
SceMoS Text (“walk to the couch”) BEV + heightmap (full room) VQ tokens on TRUMANS Imitation + heightmap decoder
CLOPS Sphere mask Ego 64×64 depth/seg Frozen AMASS prior, Q on head targets Simulator −rc on mesh overlap
Us (D, now) Text (“walk to the table”) Ego VGGT-Ω (partial) ActionPlan prior, fine-tune with sk Imitate TRUMANS GT windows

CLOPS does not learn “don’t walk through tables” from clean mocap. The AMASS prior can penetrate. After each 1 s head-target action they overlap SMPL with the Replica mesh and subtract a collision penalty. Episodes do not stop on a hit. The policy only sees ego pixels; the reward sees oracle geometry. They considered rendering TRUMANS-style ego–motion pairs and rejected it (domain gap, AMASS has no scene, demonstrations don’t search). We start with those pairs anyway because we have text goals and need to know whether VGGT cross-attention is used at all. Look-around and online rc stay in the backlog (C, then RL).

A 1 s CLIP action latent (“turn left”) is not in the loop. The last paper’s y1:N was a full-clip timeline; the receding horizon already supplies “when.” CLIP does not constrain how far to turn or how to miss a chair.

Assumptions

  1. Scene tokens enter by cross-attention into the ActionPlan denoiser. Track D drops the per-frame action-plan stream y (mask or ignore). Dual-stream ActionPlan remains the scene-free paper.
  2. Train D on native TRUMANS converted to 272, not planted HML3D. Placement is a finished diagnostic.
  3. SMPL-X → 272 uses the Xiao pipeline (272-dim-Motion-Representation), rotation recovery not IK. 22-joint body; hands/face dropped. Decode with condmdi_smpl/src/tools/streamer272_feats.py (Y-up). The copy under prepare/amasstools/ has the wrong layout and produces garbage scale.
  4. Xiao face_z is a local canonical frame for the feature window only. Do not rotate the scene mesh. Ego VGGT is already camera-centric. Keep the window’s start root in world so the body can be dropped back for render / collision.
  5. VGGT-Ω is frozen. Teacher-force first: each window’s sk comes from GT ego, not from the previous generated chunk.
  6. No SceMoS BEV as an input (oracle ablation only).
  7. Lived space is the original actor’s root trajectory, not the entire watertight Scene_mesh AABB (that AABB includes a leaky hallway).
  8. GPU work runs in tmux session gpu (A100). Do not render on the login node.
  9. Ego that should look like TRUMANS uses the textured .blend, Blender 3.6.9. Mesh-tier OBJ is untextured clay and was only a crash fallback.

Failure modes we actually hit

Hallway placements. First three matches (M014345, M005381, 014461) were collision-free at z ≈ −3.5 to −4.2 — an artifact corridor out of the room. Filled occupancy + “largest free component” + 0.5 m clearance scoring.
Hollow voxels, room AABB from GT transl (mean z ≈ 1.75 m), largest component inside the room. Ignore any folder with z ≪ 0.
Walk-through-table. Next in-room matches (002838, M011081, 006325) sat at the GT centroid. Chest-height map missed the table; 3D joint collision was soft.
Furniture band includes table height. Root-in-free-space is hard. Sample distance-transform open cells. Path length cap 2.5 m for this room.
White ego. Mesh-tier OBJ + emissive gray + camera fill. Not the TRUMANS look.
Load the .blend, strip the baked actor, add SMPL-X, Cycles OPTIX. This particular room’s walls really are pale; wood door / tiles / chair are the tell.

How big can this dataset get?

The table below was written when we still thought planted HML3D was the train set. That recipe is not the plan. D trains on native TRUMANS windows (~15 h, ~100 scenes, one trajectory per take). Scale comes from ActionPlan’s AMASS/HML3D prior, not from multiplying SE(2) poses of canned walks.

Placement numbers remain as a record of the diagnostic: not 27k clips × 688 sequences; per unique mesh (~100 rooms). This room’s diameter kills long walks.

RecipePer furnished room like this× ~100 scenes
Locomotion, 1 pose / clip (smoke recipe) — not used for D ~10² clips (7.5% of 4–10 s walks here) ~10k–100k
Same, keep several SE(2) poses — not used for D ~10²–10³ tuples maybe 2–5×
Any geometrically free HML3D (wave, stand, mid-air sit) ~10⁴–10⁵ 10⁶+, mostly junk

Real caps if we had scaled placement: path length vs room, semantics, Blender time. We are not scaling it.

Next (not built)

  1. D (now): TRUMANS SMPL-X → 272 (Xiao rotation recover). Teacher-forced windows: CLIP c from data/Actions/*.txt, frozen VGGT-Ω sk from existing ego, ActionPlan init, no y stream. Open-loop eval vs GT chunk. Table-in-view is the pass condition.
  2. A few closed-loop render → VGGT steps on one room once D open-loop is sane (still not RL).
  3. Backlog C: freeze the D-adapted prior; diffuse a geometric target (head and/or root SE(2) at +T). CLOPS-style steering interface.
  4. Backlog RL: Q/PPO on that frozen target with CLOPS −rc (SMPL vs Scene_mesh) plus named object near and in FOV. Cheap depth/mesh in the inner loop, not Cycles+VGGT. Randomized spawn and which object c names. Do not terminate on collision.
  5. Do not scale HML3D placement. SceMoS BEV only as an oracle ablation. 272 will not keep TRUMANS hand HSI.
