Claim we are aiming at

Can a human avatar navigate toward a semantically specified goal from egocentric vision only — no red sphere, no omniscient BEV, no privileged object mask?

That is CLOPS with the geometric goal replaced by grounding: map a phrase onto places in the observed 3D scene (and later, onto a place a human should stand). The motion prior stays frozen until that map exists.

Phase 0 — infrastructure (done)

Goal
Head-attached ego RGB of a TRUMANS take, plus a causal VGGT-Ω map (depth/cameras at time t from RGB ≤ t only). Demo: 2023-01-17@00-33-01. The 300-frame bidirectional pass stays on disk as an oracle.
Purpose
Later phases need a real ego stream and a 3D scene memory that did not peek at the rest of the kitchen. This is plumbing, not the paper.
Pass
Blend-tier ego matches the room. Causal recon.mp4 at frame 0 is a frontal slab, not the full apartment. See Results.

Goal
Frozen SAM 3 (image PCS, short noun) on the full ego clip. Lift masks with causal VGGT-Ω 512 geometry. No ActionPlan, no walking, no SAM 3 video tracker. The bidirectional vggt_omega/ map is an ablation, not the method.
Purpose
Isolate “does SAM 3 find the named thing in this ego window?” Failure here means phases 2–4 cannot honestly be called language-conditioned.
Pass
On the demo kitchen, for objects that are in the ego window (oven, vase, table-like surfaces we can name from TRUMANS assets): the heatmap peaks on the correct instance more often than on a random other object. Report retrieval / localization, not MPJPE.
Not yet
Off-screen objects, “walk to”, standing pose vs tabletop, fine-tuning VGGT, fine-tuning ActionPlan, SAM 3 video tracking. Native Actions/*.txt lines (“pick up the vase”) are interaction captions, not grounding queries — use object names.

Phase 2 — red-sphere equivalent

Goal
Turn the object support into a navigation goal \(g\): a point (or small set) in free space where a person would stand for “walk to X”, not the centroid of the tabletop. Feed \(g\) to a frozen motion system the same way CLOPS feeds a sphere.
Purpose
Same controller, only the goal source changes. If this works, grounding is doing the language work. If it fails, the prior/controller is the bottleneck, not the heatmap. We do not have CLOPS code; ActionPlan (or a dumb walk-toward) is the frozen prior. Inventing a geometric-target channel on ActionPlan is allowed here; jointly training scene-attn with CLIP is not.
Pass
Object starts in view. Avatar approaches a stand-pose near the named object and does not walk through it. No look-around required.

First \(g\) can be nearest free floor cell to the heatmap with clearance. Learn “where humans stand” from TRUMANS pelvis endpoints later, not in phase 1.

Phase 3 — drop the explicit point

Goal
Stop handing the controller a privileged XYZ at inference. Give it VGGT features plus language (or the heatmap field \(G(\mathbf{x})\)) and a small policy / a thin target head on the frozen prior.
Purpose
Phase 2 proves the interface. Phase 3 asks whether the explicit point was a crutch. Only start this if phase 2 already reaches.
Pass
Reach rate on the same in-view objects is comparable to phase 2 without feeding \(g\) as privileged 3D at test time.

Phase 4 — closed-loop search

Goal
\((L, I_{1:t}, M_t) \rightarrow G_t \rightarrow \pi \rightarrow\) motion \(\rightarrow\) new ego frame. The named object starts off-screen. The avatar looks, walks, updates the goal field, and approaches.
Purpose
This is the CLOPS-shaped claim. Humans do not get a sphere, and often do not see the table. SceMoS never has this problem (BEV always contains the couch).
Pass
On held-out spawns in a known room: find and approach the named object from a start pose where it is not in the first FOV, without an oracle mask.

Collision reward \(r_c\) (SMPL vs mesh), randomized object names, and not terminating on hits belong with this phase or immediately after — see Backlog. Cheap depth/mesh in the inner loop, not Cycles+VGGT.

What we are not doing in 1–4

  • SceMoS BEV as an input (oracle ablation only).
  • Scaling HML3D placement into a dataset.
  • A 1 s CLIP action latent (“turn left”) as the control.
  • End-to-end VLM → full-body motion as the first experiment.
  • Sit / look / walk-around affordances as the first paper (later on backlog).
Phase 1 is the only active stepstone. Everything else is ordered, not optional flavor.
