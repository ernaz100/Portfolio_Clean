Phase 1 — semantic 3D grounding

Goal. Given ego RGB and a name (“oven”, “vase”, “table”), mark the matching 3D points in the VGGT-Ω reconstruction. No avatar motion.

Purpose. CLOPS is told where to go (a sphere). We are told what to go to. Grounding is the map from words to places. If VGGT-Ω plus text cannot find the oven when it is in view, later “navigation” is not language-conditioned.

Pass. On this kitchen, a named object that is visible in the ego window lights up the right instance (retrieval / localization), not a random nearby surface. Details and the later phases live on Phases.

Why this, not ActionPlan fine-tune

Putting CLIP c and VGGT registers into the ActionPlan denoiser (old Track D) replaces the sphere with a text embedding. That does not say which 3D location in this room is the table. D stays a baseline, not the method. ActionPlan remains the motion prior for phases 2–4, frozen until grounding works.

SceMoS already does text-to-scene from a god’s-eye BEV. CLOPS already does ego navigation to an explicit 3D goal. The gap is ego + language → spatial goal, then a controller that never needed the sentence.
